Try Fedora from a USB drive

Back up your files before you start

Back up the important files on your computer and open a few files from the backup to make sure it works. If the USB flash drive has anything you want to keep, copy it somewhere else first. Fedora Media Writer erases everything on the USB drive you select. If your backup is on an external drive, unplug it before opening Fedora Media Writer.

A live USB lets you run Fedora Workstation directly from a flash drive without installing it on your computer. In this exercise, you’ll make a live USB, try Fedora, and return to your regular desktop.

What you’ll need

  • A 64-bit Intel or AMD PC that can start from a USB drive.
  • An empty USB flash drive. Use one with 8 GB or more.
  • An internet connection to download Fedora.
  • A phone or printed copy of these instructions so you can read them while your PC restarts.

Back up your Windows files before making the USB.

1. Make the Fedora USB

Fedora Media Writer erases the USB drive you select. Unplug other external drives before you start.

  1. Open the Fedora Workstation download page. Scroll to Fedora Media Writer and install the version for the computer you’re using to make the USB.
  2. Plug in the empty flash drive and open Fedora Media Writer.
  3. Choose the option to download Fedora automatically, then choose Fedora Workstation. If asked for a system type, choose x86_64 for your Intel or AMD PC.
  4. Select your flash drive. Check its name and capacity before proceeding. If you’re unsure, unplug the flash drive and see which entry disappears. Plug it back in and select that entry.
  5. Click Write and wait for Media Writer to finish.

2. Start the PC from the USB

  1. Save your work and restart the PC with the Fedora USB plugged in.
  2. When the manufacturer’s logo appears, tap the key for the one-time boot menu. This menu lets you choose where the PC starts for this restart. The key varies by model. Look for a Boot Menu prompt or check your PC maker’s instructions.
  3. In the boot menu, choose your USB drive. It may appear under the drive’s brand name.
  4. If the Fedora startup menu offers to test the media and start Fedora, choose that option. Once the desktop loads, select Try Fedora if a welcome window offers it. Leave Install Fedora alone for this exercise.

Did your regular desktop come back? Restart and try the boot-menu key a little sooner. If the menu opens but the flash drive is missing, try another USB port.

3. Try Fedora and return to your regular desktop

  1. Press the Windows key, type Files, and press Enter to open Fedora’s file manager.
  2. If you use Wi-Fi, open the menu in the upper-right corner and see whether Fedora lists your network. You can check without connecting.
  3. Shut Fedora down. Once the computer is fully off, remove the USB drive and turn it back on. Your regular desktop should return. Files and settings you create in the live session are temporary.

You’re done when you’ve opened an app in Fedora and returned to your regular desktop.
