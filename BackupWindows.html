How To Backup Windows

In Windows File Explorer, the left sidebar shows Local Disk (C:).

Right-click the drive and choose Properties at the bottom of the list. This shows the drive size and what is used.

If needed, inexpensive 2.5-inch laptop drives and USB external cases can be used for backups.

Part 1: Create a Recovery Drive (Windows 10)

This is needed to recover from a data disaster. Microsoft requires proper recovery media for reinstall and repair.

  1. In the lower-left search box, type Recovery Drive and open it.
  2. Confirm Backup system files is selected (this is usually the default).
  3. Click Next and wait.
  4. Select your USB flash drive from the list.
  5. Click Next. Warning: all data on that USB drive will be deleted.
  6. Click Create. This can take a long time depending on USB speed.
  7. Click Finish when the recovery drive is ready.

Part 2: Partition and Prepare the Backup Drive

Use extreme caution here. Measure twice, cut once.

  1. In the lower-left search box, type Partition and open Create and format hard disk partitions.
  2. In Disk Management, confirm the C: drive is your Windows NTFS drive.
  3. Confirm the RECOVERY USB is the device you are editing (often FAT32). Check twice.
  4. Right-click the Unallocated section.
  5. Choose New Simple Volume.
  6. In the wizard, click Next through size and drive-letter screens. Default values are usually correct.
  7. Format the volume (default NTFS is fine) and set a label like Backup.
  8. Leave Quick format checked (default), then click Finish.

Close all open windows. Your backup drive is now ready.

Part 3: Run Windows Backup

Windows encourages cloud storage, but you can still back up to USB.

  1. Open Control Panel from the lower-left search box.
  2. Go to System and Security.
  3. Select Backup and Restore (Windows 7).
  4. Select Change settings to choose the backup drive.
  5. In the pop-up window, double-click the drive you want to use.
  6. For setup, Let Windows choose is the default and recommended.
  7. Click Next.
  8. Review settings (defaults are usually fine; schedule can be changed).
  9. Click Save settings and run backup.

Backup can be started any time; you do not have to wait for the scheduled day.

While backup is running, click View details to watch progress.
