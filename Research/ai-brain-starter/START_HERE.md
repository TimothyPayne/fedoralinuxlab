# My AI brain

This is my starting folder. Fill it in with my approved information.

## Read first

- [About me](about-me.md): who I help and how I like to work.
- [Current project](current-project.md): the job we are doing now.
- [Original sources](sources/README.md): a few useful files for this job.
- [Outputs](outputs/README.md): drafts and other work I can check.

## Start here

Open this folder in your AI app as a local project. Use the setup prompt in the accompanying ai-brain-prompts.txt file. You can answer the interview questions with voice dictation.

The .md ending means Markdown, a plain-text note format. You can read these notes in a text editor or open this same folder in Obsidian.

## Keep it manageable

Work on one project first. Keep original source files unchanged, review drafts before using them, and back up the folder before reorganising it.
