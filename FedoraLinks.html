Linux: Start Here

Curious about another way to use a computer? Fedora is a Linux operating system you can use for browsing, writing, and learning computer skills. You can explore at your own pace; Linux is optional for practicing AI.

Linux comes in different flavors called distributions, or distros for short. Fedora and Ubuntu are two examples. The desktop is what you see and use on screen, including the menus and windows. Our USB exercise uses Fedora Workstation with the GNOME desktop. If you already use Linux, you can start with the system you have.

  • I already have Linux — start with the folder exercise.
  • I want to try Linux — try Fedora from a USB drive.

What is Fedora?

Fedora is developed by a community, with Red Hat as its primary sponsor. It is available without a purchase price. Like any operating system, it has its own tools and ways of doing things.

Open source means the software's license allows people to inspect, modify, and share its code. That is more than simply being free to download. You do not need to read code to use Fedora.

Start by looking around

If Fedora is already installed, try opening your file manager, finding a folder, and opening a document. You do not need to change your setup to do this.

If you use Windows, a prepared Fedora live USB lets you try Fedora without installing it. A live session runs from the USB; installing Fedora is a separate choice that can change the computer's drive.

Keep these two steps separate: making a live USB erases the USB you select. Installing an operating system can erase computer files depending on the choices you make. Back up important files first, and get help if you cannot identify the drive or understand an option.

Practice with Linux

Rename a Linux folder and undo it
  1. Open Home in your file manager. Right-click an empty space, choose New Folder (in Dolphin, Create New → Folder), and create an empty folder named Rename Practice. If either Rename Practice or Rename Practice 2 already exists, choose two unused names and remember the original. Use only the empty folder you create for this exercise.
  2. Right-click your practice folder, choose Rename, and change its name to Rename Practice 2 or your second unused name.
  3. Right away, in the same window, choose Undo Rename (in Dolphin, Undo: Rename) from the file manager menu or press Ctrl+Z once if your file manager supports it. If the original name returns, use Rename to give the folder its second name again so you can practice the next step. If Undo is unavailable and the second name is still visible, go straight to the next step.
  4. Right-click the practice folder with its second name, choose Rename, and type its original name. Confirm that the folder now shows its original name in the same location in Home.
Find your Linux version and desktop

Write down three details. In “Fedora 44 with GNOME,” they are:

  • Distribution (the Linux system you use) — Fedora
  • Version (the release of that distribution) — 44
  • Desktop environment (the interface with your menus and windows) — GNOME

Start with the menu

  • GNOME — Open Settings → System → About → System Details.
  • KDE Plasma — Search for About this System or open Info Center.
  • Xfce or LXQt — Look for About Xfce or About LXQt, if available.

Menu names and locations can vary by release. Some About windows only show the desktop name and its version. Use the terminal for any missing Linux details.

If you need the terminal

Open Terminal from your desktop’s app menu. Run these commands separately, pressing Enter after each. Both work without installing anything or using sudo.

  1. cat /etc/os-release
    Look for PRETTY_NAME, the system name as it’s meant to be shown, often with its release. Use VERSION_ID for the distribution version when that field is present.
  2. echo "$XDG_CURRENT_DESKTOP"
    This shows how your session identifies its desktop. If you see names separated by colons, copy the whole value. A blank line means this session didn’t report a desktop through that setting. Check the menu or say the desktop is unknown.

Sample output
PRETTY_NAME="Fedora Linux 44 (Workstation Edition)"
VERSION_ID=44
GNOME

In a help request, copy the three details from your own results. For this example, write Distribution Fedora Linux (Workstation Edition), Version 44, Desktop environment GNOME.

More Linux practice

A spare computer for experiments

A test box is a second computer you can afford to reset if an experiment goes wrong. Keep everyday work and your only copies of important files elsewhere. Begin with one small change, note what you did, and have a way to reinstall the operating system.

Use made-up data or copies. Keep backups on a separate drive and disconnect it during experiments. A spare machine is not automatically a secure sandbox: software can still access connected drives, accounts, or your network. Ask what a command changes before running it, and give tools only the access they need.

Try one useful file task

  • Copy selected Android photos and files to a USB drive — keep originals and check your copies.
  • Back up important Windows files to an external drive — useful before making changes to a Windows computer.

You can ask an AI tool for help, but no AI account is required to explore Fedora. Use the official guidance or ask someone experienced when a step is unclear.

Optional: make a clear help request

Describe one problem below, then select Build Prompt. This page prepares text; it does not contact an AI service or run commands. Copy the request into an AI chat you choose, or use the details when asking a person for help.

If you do not know your version or desktop, say so instead of guessing. Include the relevant error and what happened just before it.

Before sharing: remove passwords, account details, and private information from both your error text and the generated request. AI advice can be wrong. Ask what a suggested command does before running it, especially if it changes settings or files.

Other options

  • Fedora Xfce — an alternative desktop with a more traditional layout. Check its requirements and your computer's compatibility; no desktop is a guarantee that an old computer will work well.

Tip: If GNOME feels slow on your installed Fedora Workstation system, you can add Xfce without reinstalling Fedora. Open Terminal and run sudo dnf install @xfce-desktop-environment. When it finishes, sign out and choose Xfce from the session menu on the sign-in screen. GNOME stays available.

Lubuntu: another option for older equipment

Lubuntu's official website describes an Ubuntu-based Linux system designed to be lightweight, using the LXQt desktop. It is an alternative to explore alongside Fedora.

The owner of this lab reports that Lubuntu runs well on their 2008 computer. That is one person's experience, not a benchmark or a promise for every old machine. Check the current release's supported hardware, try the live USB, and test the browser and applications you actually need before installing. Modern websites can still demand substantial memory.

We have not established a performance comparison between Lubuntu and Fedora's lighter desktops. Choose using your computer's results, not its age alone. Installing can erase files, so keep a verified backup first.
