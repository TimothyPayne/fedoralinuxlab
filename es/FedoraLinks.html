Linux: Empieza aquí

¿Te da curiosidad otra forma de usar una computadora? Fedora es un sistema operativo Linux para navegar, escribir y aprender informática. Puedes explorar a tu ritmo; usar Linux es opcional para practicar con IA.

Linux tiene distintas variantes llamadas distribuciones, o distros para abreviar. Fedora y Ubuntu son dos ejemplos. El escritorio es lo que ves y usas en pantalla, incluidos los menús y las ventanas. Nuestro ejercicio con una memoria USB usa Fedora Workstation con el escritorio GNOME. Si ya usas Linux, puedes empezar con el sistema que tienes.

  • Ya tengo Linux — empieza con el ejercicio de la carpeta.
  • Quiero probar Linux — prueba Fedora desde una memoria USB.

¿Qué es Fedora?

Una comunidad desarrolla Fedora, con Red Hat como patrocinador principal. Se puede obtener sin pagar. Como cualquier sistema operativo, tiene sus propias herramientas y formas de hacer las cosas.

Código abierto significa que la licencia permite examinar, modificar y compartir el código del programa. Es más que poder descargarlo gratis. No necesitas leer código para usar Fedora.

Empieza explorando

Si Fedora ya está instalado, abre el administrador de archivos, busca una carpeta y abre un documento. No necesitas cambiar la configuración.

Si usas Windows, una unidad USB de prueba de Fedora te permite probarlo sin instalarlo. Esa sesión se ejecuta desde la USB; instalar Fedora es una decisión aparte que puede modificar la unidad de la computadora.

Distingue estos dos pasos: crear una USB de prueba borra la unidad USB seleccionada. Instalar un sistema operativo puede borrar archivos de la computadora según las opciones elegidas. Respalda los archivos importantes primero y pide ayuda si no puedes identificar la unidad o entender una opción.

Practica con Linux

Cambia el nombre de una carpeta en Linux y deshaz el cambio
  1. Abre tu carpeta personal en el gestor de archivos. Haz clic derecho en un espacio vacío, elige Carpeta nueva (en Dolphin, Crear nuevo → Carpeta) y crea una carpeta vacía llamada Rename Practice. Si ya existe Rename Practice o Rename Practice 2, elige dos nombres que estén libres y recuerda el original. Usa solo la carpeta vacía que crees para este ejercicio.
  2. Haz clic derecho en tu carpeta de práctica, elige Renombrar y cambia el nombre a Rename Practice 2 o al segundo nombre que elegiste.
  3. De inmediato, en la misma ventana, elige Deshacer renombrado (en Dolphin, Deshacer: Renombrar) en el menú del gestor de archivos o pulsa Ctrl+Z una vez si el gestor lo permite. Si vuelve a aparecer el nombre original, usa Renombrar para ponerle otra vez el segundo nombre y practicar el paso siguiente. Si la opción de deshacer no está disponible y aún ves el segundo nombre, pasa directamente al siguiente paso.
  4. Haz clic derecho en la carpeta de práctica que tiene el segundo nombre, elige Renombrar y escribe el nombre original. Comprueba que la carpeta vuelva a mostrar su nombre original en el mismo lugar de tu carpeta personal.
Encuentra tu versión de Linux y tu entorno de escritorio

Anota tres datos. En «Fedora 44 con GNOME», son:

  • Distribución (el sistema Linux que usas) — Fedora
  • Versión (la edición publicada de esa distribución) — 44
  • Entorno de escritorio (la interfaz con tus menús y ventanas) — GNOME

Empieza por el menú

  • GNOME — Abre Configuración → Sistema → Acerca de → Detalles del sistema.
  • KDE Plasma — Busca Acerca de este sistema (About this System) o abre el Centro de información (Info Center).
  • Xfce o LXQt — Busca Acerca de Xfce (About Xfce) o Acerca de LXQt (About LXQt), si aparecen.

Los nombres y la ubicación de los menús pueden variar según la versión. Algunas ventanas de información solo muestran el nombre y la versión del escritorio. Usa la terminal para encontrar los datos de Linux que te falten.

Si necesitas usar la terminal

Abre Terminal desde el menú de aplicaciones de tu escritorio. Ejecuta estos comandos por separado y presiona Intro después de cada uno. Puedes usarlos sin instalar nada ni usar sudo.

  1. cat /etc/os-release
    Busca PRETTY_NAME, el nombre del sistema tal como se muestra al usuario, a menudo con su versión. Usa VERSION_ID para identificar la versión de la distribución si aparece ese campo.
  2. echo "$XDG_CURRENT_DESKTOP"
    Esto muestra cómo identifica el escritorio tu sesión. Si ves nombres separados por dos puntos, copia el valor completo. Una línea en blanco significa que la sesión no indicó el escritorio en ese ajuste. Revisa el menú o indica que desconoces el escritorio.

Ejemplo de resultado
PRETTY_NAME="Fedora Linux 44 (Workstation Edition)"
VERSION_ID=44
GNOME

Al pedir ayuda, copia los tres datos de tu propio resultado. Para este ejemplo, escribe Distribución Fedora Linux (Workstation Edition), Versión 44, Entorno de escritorio GNOME.

Más práctica con Linux

Una computadora adicional para experimentar

Una computadora de pruebas es un segundo equipo que puedes restablecer si un experimento sale mal. Guarda el trabajo diario y las únicas copias de archivos importantes en otro lugar. Empieza con un cambio pequeño, anota lo que hiciste y ten una forma de reinstalar el sistema operativo.

Usa datos inventados o copias. Guarda respaldos en una unidad aparte y desconéctala durante los experimentos. Un equipo adicional no es automáticamente un entorno aislado y seguro: los programas pueden acceder a unidades conectadas, cuentas o tu red. Pregunta qué cambia un comando antes de ejecutarlo y da a las herramientas solo el acceso necesario.

Prueba una tarea útil con archivos

  • Copia fotos y archivos seleccionados de Android a una unidad USB — conserva los originales y comprueba las copias.
  • Respalda archivos importantes de Windows en una unidad externa — útil antes de hacer cambios en una computadora con Windows.

Puedes pedir ayuda a una herramienta de IA, pero no necesitas una cuenta de IA para explorar Fedora. Consulta las instrucciones oficiales o pide ayuda a alguien con experiencia cuando un paso no esté claro.

Otras opciones

  • Fedora Xfce — un escritorio alternativo con una distribución más tradicional. Revisa los requisitos y la compatibilidad con tu computadora; ningún escritorio garantiza que una computadora antigua funcione bien.

Consejo: Si GNOME va lento en tu equipo con Fedora Workstation instalado, puedes agregar Xfce sin reinstalar Fedora. Abre la terminal y ejecuta sudo dnf install @xfce-desktop-environment. Cuando termine, cierra la sesión y elige Xfce en el menú de sesiones de la pantalla de inicio de sesión. GNOME seguirá disponible.

Lubuntu: otra opción para equipos antiguos

El sitio oficial de Lubuntu describe un sistema Linux basado en Ubuntu, diseñado para consumir pocos recursos y que usa el escritorio LXQt. Es otra alternativa para explorar junto con Fedora.

El responsable de este laboratorio comenta que Lubuntu funciona bien en su computadora de 2008. Es una experiencia personal, no una prueba comparativa ni una promesa para todos los equipos antiguos. Revisa el hardware compatible con la versión actual, prueba la USB y comprueba el navegador y las aplicaciones que necesitas antes de instalar. Los sitios web modernos pueden requerir bastante memoria.

No hemos establecido una comparación de rendimiento entre Lubuntu y los escritorios más ligeros de Fedora. Elige según los resultados de tu computadora, no solo su antigüedad. La instalación puede borrar archivos, así que conserva primero un respaldo comprobado.
