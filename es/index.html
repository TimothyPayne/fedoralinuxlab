AI Practice Lab · Palabras de IA, en lenguaje sencillo

Inteligencia artificial (IA)
Sistemas de computadora que realizan tareas como reconocer patrones, trabajar con el lenguaje o hacer predicciones.
IA generativa
IA que crea contenido, como texto, imágenes, audio o video.
Chatbot
Un programa con el que conversas por mensajes. Algunos chatbots usan IA generativa.
Solicitud (prompt)
La pregunta, las instrucciones o la información que das a una herramienta de IA.
Mensaje de seguimiento
Otro mensaje que agrega detalles, hace una pregunta o pide un cambio.
Contexto
La información disponible para la respuesta actual de la IA, como las instrucciones y partes de la conversación.
Modelo
El sistema matemático entrenado que usa una herramienta de IA para producir resultados.
Entrenamiento
El proceso de ajustar un modelo con ejemplos u otros comentarios. Una conversación normal no necesariamente vuelve a entrenar el modelo.
Token
Una unidad pequeña que usa un modelo para procesar información. En texto, puede ser parte de una palabra, una palabra completa o un signo de puntuación.
Modelo de lenguaje grande (LLM)
Un modelo entrenado con grandes cantidades de texto para trabajar con el lenguaje, por ejemplo, generar respuestas.
Alucinación
Una respuesta de IA que incluye información inventada o incorrecta, aunque parezca segura de lo que dice.
Sesgo
Patrones que pueden hacer que un sistema de IA trate de forma injusta a personas o ideas, o dé un resultado parcial.
Verificación
Revisar un resultado con fuentes confiables o pruebas del mundo real antes de usarlo.
Automatización
Usar programas o máquinas para realizar pasos con menos trabajo manual.
Agente de IA
Un sistema de IA que puede usar herramientas y dar pasos hacia una meta. Sus acciones y permisos aún necesitan supervisión humana.
