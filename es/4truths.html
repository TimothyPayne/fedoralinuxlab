4 verdades para cada día

Reflexión budista

«Si un problema tiene solución, si puedes hacer algo para resolver una situación, no hay necesidad de preocuparse. Si no tiene solución, preocuparse no ayuda. Preocuparse no aporta ningún beneficio».

Dalái Lama XIV


Intenta aplicar estas verdades en tu vida diaria.
  1. El pasado no se puede cambiar.
  2. La felicidad se encuentra dentro de uno mismo.
  3. La amabilidad es gratuita.
  4. Solo fracasas si abandonas.
