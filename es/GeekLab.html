Encuentra tu versión de Linux y tu entorno de escritorio

Anota tres datos. En «Fedora 44 con GNOME», son:

  • Distribución (el sistema Linux que usas) — Fedora
  • Versión (la edición publicada de esa distribución) — 44
  • Entorno de escritorio (la interfaz con tus menús y ventanas) — GNOME

Empieza por el menú

  • GNOME — Abre Configuración → Sistema → Acerca de → Detalles del sistema.
  • KDE Plasma — Busca Acerca de este sistema (About this System) o abre el Centro de información (Info Center).
  • Xfce o LXQt — Busca Acerca de Xfce (About Xfce) o Acerca de LXQt (About LXQt), si aparecen.

Los nombres y la ubicación de los menús pueden variar según la versión. Algunas ventanas de información solo muestran el nombre y la versión del escritorio. Usa la terminal para encontrar los datos de Linux que te falten.

Si necesitas usar la terminal

Abre Terminal desde el menú de aplicaciones de tu escritorio. Ejecuta estos comandos por separado y presiona Intro después de cada uno. Puedes usarlos sin instalar nada ni usar sudo.

  1. cat /etc/os-release
    Busca PRETTY_NAME, el nombre del sistema tal como se muestra al usuario, a menudo con su versión. Usa VERSION_ID para identificar la versión de la distribución si aparece ese campo.
  2. echo "$XDG_CURRENT_DESKTOP"
    Esto muestra cómo identifica el escritorio tu sesión. Si ves nombres separados por dos puntos, copia el valor completo. Una línea en blanco significa que la sesión no indicó el escritorio en ese ajuste. Revisa el menú o indica que desconoces el escritorio.

Ejemplo de resultado
PRETTY_NAME="Fedora Linux 44 (Workstation Edition)"
VERSION_ID=44
GNOME

Al pedir ayuda, copia los tres datos de tu propio resultado. Para este ejemplo, escribe Distribución Fedora Linux (Workstation Edition), Versión 44, Entorno de escritorio GNOME.

Cambia el nombre de una carpeta en Linux y deshaz el cambio
  1. Abre tu carpeta personal en el gestor de archivos. Haz clic derecho en un espacio vacío, elige Carpeta nueva (en Dolphin, Crear nuevo → Carpeta) y crea una carpeta vacía llamada Rename Practice. Si ya existe Rename Practice o Rename Practice 2, elige dos nombres que estén libres y recuerda el original. Usa solo la carpeta vacía que crees para este ejercicio.
  2. Haz clic derecho en tu carpeta de práctica, elige Renombrar y cambia el nombre a Rename Practice 2 o al segundo nombre que elegiste.
  3. De inmediato, en la misma ventana, elige Deshacer renombrado (en Dolphin, Deshacer: Renombrar) en el menú del gestor de archivos o pulsa Ctrl+Z una vez si el gestor lo permite. Si vuelve a aparecer el nombre original, usa Renombrar para ponerle otra vez el segundo nombre y practicar el paso siguiente. Si la opción de deshacer no está disponible y aún ves el segundo nombre, pasa directamente al siguiente paso.
  4. Haz clic derecho en la carpeta de práctica que tiene el segundo nombre, elige Renombrar y escribe el nombre original. Comprueba que la carpeta vuelva a mostrar su nombre original en el mismo lugar de tu carpeta personal.
